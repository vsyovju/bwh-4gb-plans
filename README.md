这是官网目前月付最便宜的 4GB VPS，没有之一。4 核 CPU、80GB SSD、每月 3TB 流量，纸面配置对个人用户来说相当能打。

但它便宜是有原因的：走的是普通国际线路，不对中国大陆做任何优化。晚上高峰期从国内连过去，卡顿和丢包是常见现象。官方页面也写明这款支持在 DC3、DC8 等 9 个机房之间免费迁移，可迁移归可迁移，线路本身的天花板不会因为换机房而改变。

## 4GB 内存到底能干什么

最后回到配置本身。4GB 内存 + 4 核 CPU 在 VPS 里属于"够用且有富余"的档位，常见的玩法：

- WordPress 或个人博客，加上 MySQL 和 Nginx，内存占用通常不到一半
- 中小规模的 API 网关或应用后端
- 轻量数据库、定时任务、爬虫
- 三五个朋友拼车合租，3TB 流量分摊下来人均成本很低

再往上，比如跑大型数据库、多个重载服务并行、或者编译大型项目，就该看 8GB 档了（CN2 GIA-E 8GB 年付 $879.99，KVM 8GB 年付 $399.99），这里不展开。
